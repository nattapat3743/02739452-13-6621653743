# DESIGN.md — Quake Monitor

แนวทางออกแบบได้แรงบันดาลใจจาก DESIGN.md ของ Starbucks ใน https://getdesign.md/starbucks/design-md
(พื้นครีมอุ่น, เขียวหลายระดับที่แต่ละเฉดมีหน้าที่ชัดเจน, ปุ่มแคปซูลเต็ม, การ์ดมุม 12px เงาบางมาก, กดแล้วยุบ)
ปรับให้เข้ากับ Streamlit และภาษาไทย ไม่ได้ใช้โลโก้หรือฟอนต์เฉพาะของแบรนด์
โค้ดอยู่ใน `theme.py` และ `.streamlit/config.toml`

## สี

| Token | Hex | ใช้ที่ |
|---|---|---|
| canvas | `#F2F0EB` | พื้นหลังหน้า, กล่องหมายเหตุ, tile |
| white | `#FFFFFF` | การ์ด, menu bar, input |
| brand | `#006241` | หัวข้อหน้า (H1), ตัวเน้นในหมายเหตุ |
| accent | `#00754A` | ปุ่ม, เมนูที่เลือก, segmented control ที่เลือก, แหล่ง TMD |
| house | `#1E3932` | การ์ด KPI เด่น, footer, หัวการ์ด, ตัวเลข, แหล่ง USGS |
| mint | `#D4E9E2` | hover ของตัวเลือก, badge สำเร็จ, แถบซ้ายของ KPI |
| gold | `#CBA258` | หัวข้อ footer, แถบของ KPI เด่น, แหล่ง EMSC |
| muted | `#6E6E6B` | label, คำอธิบาย |

ไล่สีตามขนาด/ความลึก: `mint → #5FA383 → accent → house`

## ตัวอักษร
- **Nunito Sans** (ละติน) ซึ่ง DESIGN.md แนะนำเป็นตัวแทนฟอนต์ SoDoSans ที่ "อบอุ่นแบบคาเฟ่" + **IBM Plex Sans Thai** (ไทย)
- letter-spacing −0.01em ทั้งเว็บ
- ตัวพิมพ์ใหญ่ +0.1em ใช้เฉพาะ eyebrow, label ของ KPI และหัวคอลัมน์ใน footer

## Component
- **ปุ่มทุกปุ่ม:** แคปซูลเต็ม (radius 50px) เส้นขอบเขียว พอ hover จะเติมสีเขียว กดแล้วยุบ `scale(.95)` transition 0.2s
- **การ์ด:** พื้นขาว มุม 12px เงา `0 0 .5px rgba(0,0,0,.14), 0 1px 1px rgba(0,0,0,.24)` พอ hover เงาลึกขึ้น
- **KPI:** การ์ดขาวมีแถบซ้าย 4px (mint → เขียวเมื่อ hover) ใบเด่นเป็นพื้น house green แถบทอง
- **หัวข้อส่วน:** มีเส้นเขียว 4px ด้านซ้าย
- **Menu bar:** แคปซูลขาวลอยด้านบน หน้าที่เลือกเป็นแคปซูลเขียว hover แสดงเส้นขอบเขียว
- **Input:** แคปซูลขาว พอ focus ขอบเป็นสีเขียวและมีวงแสงเขียวจาง ๆ
- **Pagination:** ปุ่ม ‹ › แบบแคปซูลเส้นขอบเขียว และป้าย "หน้า x / y" บนพื้นครีม
- **Footer:** พื้น house green หัวข้อสีทอง ลิงก์สีขาวที่เปลี่ยนเป็นทองเมื่อ hover
- **ปุ่มลอย (Frap):** วงกลมเขียว 56px มุมขวาล่าง กดแล้วกลับขึ้นด้านบน มีเงาสองชั้น
